# Intro to Virtualization: Portfolio & Project Repository

## Overview
Welcome to my portfolio repository for **Intro to Virtualization**. This workspace documents my hands-on labs, scenario-based investigations, and technical evaluations exploring how virtualization, containers, and cloud compute models abstract underlying hardware to optimize resource allocation and performance.

---

## Undergraduate Program Objectives Alignment

This portfolio is systematically organized to demonstrate mastery across our core program objectives:

### 1. Complex Problem Analysis & Solution Determination
* **Application:** Dissecting complex infrastructure and resource-utilization challenges to determine root causes and recommend appropriate virtualization models.
* **Evidence:** Analyzing legacy single-server bottlenecks (e.g., evaluating shared EC2 instances hosting mixed workloads like morning reports and intermittent APIs) to determine optimal compute sizing.

### 2. Solution Implementation & Evaluation
* **Application:** Composing, implementing, and evaluating proposed technology solutions that satisfy rigorous functional and operational requirements.
* **Evidence:** Evaluating trade-offs between traditional virtual machines, containerization (Docker/ECS/Fargate), and serverless execution (AWS Lambda) to eliminate idle overhead and streamline deployment.

### 3. Professional Communication Skills
* **Application:** Communicating technical insights, architectural plans, and engineering recommendations clearly across professional contexts.
* **Evidence:** Drafting concise, professional README files, technical memos, and structured workload migration recommendations for engineering leadership.

### 4. Legal, Ethical, & Professional Responsibilities (Part 1)
* **Application:** Grounding technology and cloud practices in industry best practices for security and access management.
* **Evidence:** Applying least-privilege IAM access principles and secure configuration standards when provisioning virtualized environments and services.

### 5. Legal, Ethical, & Professional Responsibilities (Part 2)
* **Application:** Making informed, responsible operational recommendations rooted in system reliability and compliance.
* **Evidence:** Establishing structured escalation paths for resource constraints, security boundaries, and infrastructure changes.

### 6. Effective Collaboration & Individual Operation
* **Application:** Demonstrating accountability, autonomy, and collaborative strength in course-based projects and technical investigations.
* **Evidence:** Maintaining clean, modular, and reproducible project documentation designed to support both independent execution and team review.
